# Architecture

## Execution plane

`/api/workflow` invokes the deterministic server recovery engine. The browser receives a completed event stream and replays it visually; business state transitions are not generated by browser timers.

## Receipt plane

The engine emits a `rialo-rewind.receipt.v2` JSON object. The SHA-256 hash covers the receipt payload while excluding `receiptHash` and `onchainAnchor`, allowing anchor evidence to be attached without changing the protected workflow hash.

## Rialo anchor plane

`/api/anchor` derives a deterministic Rialo recipient from the receipt hash, funds a disposable devnet payer, sends a commitment transfer, and records signature and account-state evidence. Verification recomputes the expected commitment address and checks transaction-index or account-state finality.

## Verification plane

The exported receipt is parsed and hashed in the browser. The full file is not uploaded. Only public anchor evidence is sent to the read-only anchor verification endpoint. Local hash failure blocks the chain query.

## Reporting plane

R1.4.1 can copy a human-readable verification summary or download `rialo-rewind.verification-report.v1`. Reports contain public proof metadata and explicitly state that the full receipt was not uploaded.
